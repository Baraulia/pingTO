    Ammo and compensation (POST, DELETE, PUT, PATCH)
    
            
    Same POST or DELETE without unique cartridges will collide: duplicate keys, 404 after the first delete, dirty data. Ammo is a JSON array of shots. Empty object fields inherit the current request. {n} is the 1-based shot index for this run. Compensation runs only after a successful main request and is not counted in RPS. Global compensate is method + URL with {n} only — a single body cannot describe thousands of different shots; put compensate.body on the cartridge.
    
            
            
    
              
              
              
            
    
            
    Abort if the service cannot hold
    
            
    The test stops itself (status aborted) when the API is failing or too slow. 0 disables a rule. Checks start after the grace period and a minimum number of requests, so a couple of errors at the start do not trip it.
