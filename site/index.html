Load testing Pro

Load tests that run on your machine

Chrome cannot open thousands of parallel connections, so PingTo drives a small agent you download for your OS. It repeats the current HTTP request and streams results back to the extension.

  1. Download the agent

    Builds for Windows, macOS and Linux from GitHub Releases, with a SHA-256 checksum to verify.

  2. Run it locally

    Listens on 127.0.0.1:8788 only. No login and no telemetry.

  3. Ramp or hold

    Grow from zero to a target rate, or hold the peak. Abort rules stop the run on error rate, p95 latency or a streak of failures.

  4. Read the report

    Live and peak requests per second, p50/p95/p99 latency and status codes. Export the report as HTML.

Privacy

What leaves your computer

PingTo is built to work without a backend. These are the only network calls it makes on its own.

  • Requests you send, collections, environments and history stay in chrome.storage.local on this device.
  • License activation and deactivation call Lemon Squeezy.
  • The load-test agent and its release manifest are downloaded from GitHub only when you use that feature.
  • Pro scripts run in an isolated sandbox page without access to extension APIs.
  • There is no account system and no cloud workspace.

FAQ

Questions

Do I need an account?

No. Install the extension and send requests. A license key is only needed for Pro.

Where is my data stored?

In chrome.storage.local on this device. Use PingTo JSON export or the Pro workspace file to move it to another computer.

How many devices does a Pro license cover?

Up to three. Activate the same key on each device; deactivate one to free a slot.

What happens if I do not renew Pro?

Your data stays. Pro features lock, and collections beyond the first two are locked, not deleted, until you renew.

Can PingTo ignore invalid TLS certificates?

No. Chrome extensions cannot bypass certificate errors. Use a valid certificate, or plain HTTP for local services.

Is the load-test agent safe to run?

It listens on 127.0.0.1 only and has no telemetry. It also has no login, so any program on this computer can call it while it runs. Stop it when you are done, and load only APIs you own or are permitted to test.
